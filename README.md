# ✈️ Takamatsu Bespoke Journey

다카마쓰(Takamatsu) 맞춤형 여행 일정표 및 가이드 웹페이지를 제공하는 프로젝트입니다. 아름다운 세토내해의 관문인 다카마쓰를 여행하는 데 필요한 일자별 타임라인, 목적지 상세 정보, 교통수단 가이드 및 꿀팁들을 한 곳에서 편리하게 확인할 수 있도록 구성되어 있습니다.

## 🌟 주요 기능 (Key Features)

- **상세한 일자별 타임라인 (Day-by-Day Timeline)**: 각 일자(DAY 01, DAY 02 등)의 이동 시간, 장소, 추천 활동을 시각적으로 명확하게 제공합니다.
- **직관적인 UI/UX**: 주요 스팟 이미지, 구글 맵 경로 링크, 소요 비용, 이동 수단 등을 위젯 및 뱃지 형태로 한눈에 파악할 수 있습니다.
- **유용한 여행 팁 (Travel Tips)**: 현지에서 꼭 알아야 할 환승 정보, 맛집 정보, 면세 혜택 등 유용한 꿀팁을 `Tip Box` 형태로 제공합니다.
- **반응형 디자인 (Responsive Web)**: 모바일 환경에서 여행 중 쉽게 열어볼 수 있도록 최적화된 모바일 친화적 인터페이스를 적용했습니다.

## 📁 디렉토리 구조 (Repository Structure)

이 저장소는 다카마쓰 여행 가이드라인을 보여주기 위한 정적 리소스와 메인 HTML 웹페이지로 구성되어 있습니다.

- `index.html`: 여행 일정표 메인 웹페이지
- `*.jpg`, `*.png`, `*.pdf`: 각 타임라인과 일정에 필요한 참고 이미지 및 PDF 지도 자료
- `refactor.js` / `refactor.py`: 웹 자동화 또는 내부 자산 변경/비율 조정 등을 위한 사이드 유틸리티 스크립트

## 🚀 시작하기 (Getting Started)

별도의 빌드 과정 없이 `index.html` 파일을 브라우저에서 실행하기만 하면 전체 여행 일정을 바로 확인할 수 있습니다!

1. 저장소를 클론(Clone)하거나 다운로드합니다.
2. 폴더 내의 `index.html` 파일을 더블클릭하여 데스크톱 브라우저에서 엽니다.
3. 모바일 환경의 경우 로컬 서버를 띄워 접속하면 더욱 쾌적하게 확인할 수 있습니다.
